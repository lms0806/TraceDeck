# TraceDeck

원격 Linux 서버를 위한 SSH 작업 공간입니다. PuTTY·MobaXterm처럼 서버에 연결하되, SFTP 파일 탐색, 실시간 로그 확인, tracing 로그 분석, ANSI 터미널을 하나의 Tauri 데스크톱 앱에서 제공합니다.

## 주요 기능

- **저장 세션**: 호스트, 포트, 사용자, 개인키 경로 또는 SSH agent 기반 연결 프로필을 로컬에 저장합니다.
- **다중 서버 탭**: 여러 서버를 동시에 열고, 드래그로 탭 순서를 바꾸거나 탭별로 작업 상태를 유지합니다.
- **원격 파일 탐색**: SFTP로 폴더를 열고 이동하며, 파일을 선택하면 최신 100줄을 미리 봅니다.
- **실시간 로그**: 선택한 파일을 원격 `tail -F`로 추적합니다. 로그와 터미널은 같은 하단 도크에서 탭으로 전환하며, 도크 높이는 드래그로 조절할 수 있습니다.
- **SSH 터미널**: PTY 기반 SSH 셸과 xterm.js 렌더러를 사용합니다. ANSI 색상·커서·화면 제어를 처리하며, 창 크기에 맞춰 원격 터미널 크기도 갱신합니다.
- **tracing 로그 분석**: 여러 `.log` 파일을 선택해 `timestamp level target: message` 형식의 tracing 로그를 모으고, 레벨과 코드 모듈(target)별로 집계합니다.

## 인증 방식

현재 UI에서 지원하는 인증 방식은 다음과 같습니다.

- 개인키 파일: OpenSSH가 읽을 수 있는 개인키 파일 경로를 지정합니다.

SSH agent 연결은 백엔드 프로필 형식과 OpenSSH 실행 계층에서 호환되며, UI 선택 항목은 추가 예정입니다. 비밀번호 인증은 현재 지원하지 않습니다. 개인키 파일 자체는 앱에 복사하거나 저장하지 않으며, 프로필에는 파일 경로만 보관합니다.

처음 연결하는 서버의 호스트 키는 OpenSSH의 `accept-new` 정책으로 로컬 known-hosts 파일에 기록됩니다. 이후 서버 키가 바뀌면 연결을 중단해 확인할 수 있도록 합니다.

## 요구 사항

- Windows 10/11의 OpenSSH Client (`ssh`, `sftp` 명령)
- Rust stable toolchain
- Node.js 및 pnpm

## 실행

```powershell
pnpm install
pnpm tauri dev
```

앱에서 **새 세션**을 열고 호스트·사용자·개인키를 입력한 뒤 연결을 확인합니다. 파일 화면에서 폴더를 열고 로그 파일을 선택하거나, **하단 터미널**을 열어 원격 명령을 입력할 수 있습니다.
